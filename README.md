# DRIVE X — бозии кушод барои Android

Godot 4.3 (GL Compatibility) + GDScript. Забони бозӣ: тоҷикӣ.

## Чӣ дорад
- Харитаи кушоди 2.4×2.4 км бо **3 намуди роҳ**: шоҳроҳ, кӯчаҳои шаҳр, роҳи кӯҳии хокӣ (суръат ва часпиш фарқ мекунад).
- Одами бозӣ: пиёда гаштан, муштзанӣ, лагад, ҳимоя; савор ва фуруд омадан аз мошин.
- Одамони шаҳр (мардум) ва ҷанговарони кӯча (задухӯрд, мукофот — танга).
- Пойгаҳо бо нишонаҳои кабуд дар харита (4 пойга, рақибони AI).
- Гараж (5 мошин, беҳсозӣ), Либос (болопӯш, шим, пойафзол, кулоҳ, ранги пӯст).
- Мундариҷа бо JSON: иловаи мошин/либос/персонаж бе тағйири код — `docs/ADDING_CONTENT.md`.

## Сохтани APK
Push ба `main` → GitHub Actions: санҷиши сохтор → import → self-test → smoke-test → export → санҷиши APK.
Логҳои Godot дар Summary-и иҷро ва дар артефакти `DRIVE-X-build-logs` нишон дода мешаванд.

## Идоракунӣ
Пиёда: ҷойстик, МУШТ/ЛАГАД/ҲИМОЯ, САВОР ШАВ; экранро кашед — камера давр мезанад.
Мошин: тирчаҳо, ГАЗ, ТАРМОЗ, НИТРО, ДРИФТ, ФУРУД. Клавиатура: WASD, E, J, K, Q, Shift, Space, C, R, Esc.

## Навсозии бехатар
`tools/safe_update.sh` пеш аз тағйирот нусхаи эҳтиётӣ мегирад. Пешрафти бозингар дар `user://` ва ба навсозӣ дахл надорад.

## Маҳдудиятҳо (тасдиқ нашудаанд)
- APK ҳанӯз дар CI сохта нашудааст (дар ин муҳит Godot нест); аввалин иҷрои CI санҷиши воқеист.
- Танҳо APK-и debug; барои release калиди шахсӣ лозим.
- Идора бо моил: самт дар дастгоҳи воқеӣ санҷида нашудааст.
- Моделҳо процедурианд; Blender-скрипт ихтиёрист. Трафики мошинҳо дар шаҳр нест.
